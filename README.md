# ARC-Engine
Game Engine started during the SRIP program and continued into the ACST course

## Authors
Noah Butler

## Libraries and Equipment
* HTML, CSS, Javascript - For front end design and engine logic
* WebGL - For canvas rendering in 2D and 3D
* Node and ExpressJS - Server handling authentication, session, and account management
* WebXR - For virtual reality game development support
* Brython Transpiler - For programming in Python instead of Javascript
* Photoshop - For sprites and sample assets

# Feature List
- [ ] Gamifies the coding experience to provide visual feedback and learning to students interested in programming.
- [ ] Allows users to visually create the layout of their games and then implement logic behavior through code, teaching them the basics of object-oriented programming.
- [ ] Stores each user's program data in a database tied to their Google account for ease of access across multiple devices.
- [ ] Runs on the web with potential support as a web application later on.
- [ ] Uses a web server to serve program files to each user.
- [ ] Supports a custom programming language that gets interpreted into Javascript, so the site is easier to learn for users that are new to programming.
- [ ] Support for Python will be implemented as well in order to allow programmers of various backgrounds.
- [ ] Contains sample projects and tutorials for new users to follow and learn the language.
- [ ] Supports 2D and 3D games using WebGL with access to many built-in methods that make development easier.
- [ ] Supports VR headsets for virtual reality game development running entirely in the web using WebXR.
- [ ] Supports multiplayer games and multiplayer game development in the editor.
